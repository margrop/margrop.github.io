Home Assistant Security Audit & AI Agent Guardrails Toolkit
=============================================================

Zero-dependency Python 3 standard library toolkit.
Compatible with Windows 11, Ubuntu 26.04, and macOS 27.

Quick commands:
- Windows 11:    powershell .\windows-11.ps1 probe --url "http://homeassistant.local:8123"
- Ubuntu 26.04:  bash ./ubuntu-26.04.sh probe --url "http://homeassistant.local:8123"
- macOS 27:      zsh ./macos-27.sh probe --url "http://homeassistant.local:8123"
- AI Agent JSON: python3 ha_security_toolkit.py agent-audit -c config.example.json
