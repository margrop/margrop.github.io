# HACS Beginner Automation Toolkit

Zero-dependency cross-platform automation suite for Home Assistant Community Store (HACS).

## Quick Start

### Windows 11 (PowerShell 7)
```powershell
.\windows-11.ps1 check
.\windows-11.ps1 install --config-dir C:\path\to\config
```

### Ubuntu 26.04 LTS (Bash)
```bash
bash ubuntu-26.04.sh check
bash ubuntu-26.04.sh install --config-dir /config
```

### macOS 27 (Zsh)
```zsh
zsh macos-27.sh check
zsh macos-27.sh install --config-dir ~/.homeassistant
```
