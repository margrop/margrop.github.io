诺奖得主送的免费实验室：PhET 173 个仿真实验，断网也能上课（附三端一键离线包）

发布时间: 2026-10-19 · 阅读量 --
教育 Education 学习 Learning 网站推荐 浏览器 自动化 Automation Windows 11 Ubuntu 26.04 macOS 27

想让学生看见电子怎么绕着原子核转、炮弹为什么走抛物线、冰为什么会化成水？以前要么靠老师在黑板上画，要么靠一间器材齐全的实验室。

现在有一个更省事的办法：打开浏览器，进入 PhET 互动仿真程序。它由诺贝尔物理学奖得主创办，完全免费，官网写着 173 个互动仿真、132 种语言，累计被使用 18 亿次。

这篇文章先带你把 PhET 用起来，再解决一个老师们最常遇到的现实问题：机房网络差、教室不能联网，怎么办？我把官网的单文件仿真做成了三端一键离线包，还顺手挖出了一个小细节：离线打开仿真时，它仍然会悄悄尝试“寄回执”。

图 1：本文原创示意图。

一、PhET 是什么：一个诺奖得主做的“免费实验室”

PhET 的全称是 PhET Interactive Simulations，中文官网叫“PhET 互动仿真程序”，中文入口是 phet.colorado.edu/zh_CN。它由 2001 年诺贝尔物理学奖得主卡尔·威曼（Carl Wieman）于 2002 年创立，由美国科罗拉多大学博尔德分校的团队长期运营。

它做的事情很简单：把物理、化学、生物、地球科学和数学里的经典实验，做成可以拖、拉、点、调的互动小程序。学生不是“看动画”，而是自己动手改参数，马上看到结果。

图 2：真实网页截图，来源 PhET 中文官网，截取于 2026-10-19。

首页往下翻，能看到三组数字：173 个互动式模拟教材、132 种语言翻译、3702 份教师投稿的教案。

图 3：真实网页截图，来源 PhET 中文官网，截取于 2026-10-19。

这里有一个细节值得说清楚。我用 PhET 官方的元数据接口核对了一遍，当前能直接在浏览器运行的 HTML5 仿真是 122 个，其中 106 个有简体中文版。首页的 173 还包含了一部分老的 Java 版仿真和其他形态。对大多数老师和学生来说，122 个 HTML5 仿真已经覆盖了中小学到大学低年级的大部分核心概念。

另一个小发现：简体中文首页里混着不少繁体字，比如“模擬教材”“語言翻譯”。这是翻译还没完全统一造成的，不影响使用。真正进入仿真程序之后，界面基本是规范的简体中文。

二、为什么“玩”能学懂科学：先打个比方

很多家长第一次听说“用仿真学物理”，会担心：这不就是玩游戏吗？

换个角度想就明白了。学开车的人，很多会先在驾校的模拟器里练方向盘和刹车：撞了没关系，重来就行，也不会真的伤人。等手感有了，再上真车。

PhET 对科学课的作用，就像这台“驾校模拟器”。

图 4：本文原创示意图。仿真不替代动手实验，而是让动手之前先想明白。

真实实验室有三个天然的限制。第一，器材贵，一所学校不一定买得起示波器和光谱仪。第二，有危险，强酸、高压电、放射性都不能让学生随便试。第三，很多东西肉眼看不见，比如原子、电流、分子的运动。

PhET 官方在“关于我们”里写了它的设计原则，其中一句特别关键：Make the invisible visible，把看不见的东西画出来。电子在导线里流动，分子在加热时越跑越快，这些在仿真里都能直接看到。

而且每个仿真都经过学生访谈和课堂观察测试，才正式发布。它不是随手做的小游戏，而是基于教育研究反复打磨的教学工具。

三、三分钟上手：找到你要的实验

打开中文官网，点顶部“仿真程序”，就能按学科浏览全部仿真：物理、数学、化学、地球科学、生物。

图 5：真实网页截图，来源 PhET 仿真浏览页，截取于 2026-10-19。

点进任意一个仿真，比如“斜抛运动”，会看到它的详情页。这里有三样东西值得注意：

第一，中间的大播放按钮，点一下就在浏览器里直接运行。

第二，标题下方那一排小图标，第一个就是下载按钮，可以把这个仿真保存成一个 HTML 文件。

第三，下方的“学习目标范例”和“教师资源”，告诉老师这个仿真能教什么，还能找到其他老师分享的教案。

图 6：真实网页截图，来源 斜抛运动仿真页，截取于 2026-10-19。页面显示版本 1.0.34。

系统要求也很低：官方说明 HTML5 仿真可以在 iPad、Chromebook、Windows 电脑、Mac 和 Linux 上运行，不需要装插件，有一个现代浏览器就够了。

四、三个实验，看看课堂上怎么用

实验 1：斜抛运动，炮弹为什么走弧线

在“斜抛运动”的“入门”界面里，左边是一门架在高台上的大炮，下面可以调初速度，右边可以换炮弹种类，从南瓜、棒球到汽车都有。点红色的发射按钮，就能看到一条完整的轨迹，还能用卷尺量射程。

图 7：真实仿真截图，本文离线课件包在断网状态下运行。Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY-NC 4.0。

这个仿真最适合用“预测、动手、观察、解释”四步来上课。

图 8：本文原创示意图。

先让学生猜：“炮管抬多高，炮弹飞得最远？”很多人会说 60 度，因为“越高越远”。然后让他们自己拖动炮管试。没有空气阻力时，从地面发射，45 度飞得最远；勾上“空气阻力”，答案又会变小一点。最后让学生用自己的话解释原因。

这就是仿真的威力：猜错的学生不会觉得丢脸，因为仿真在“告诉”他，而不是老师在“纠正”他。

实验 2：物质状态，冰是怎么化成水的

“物质状态”仿真里，一个容器装着一堆小球，每个小球代表一个原子或分子。下面有个加热和制冷的旋钮，右边可以一键切换固体、液体、气体。

图 9：真实仿真截图，断网运行。Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY-NC 4.0。

打个比方：固体像早操时站好队的同学，只能原地小幅晃动；液体像下课的同学，挤在一起但可以到处走；气体像放学冲出校门的同学，四处乱跑。往容器里加热，就像打了下课铃，小球越动越快，队伍就散了。

对小学生来说，这比背“分子间作用力”四个字好懂得多。对中学生，还可以打开温度计，观察温度和运动速度的关系。

实验 3：原子模型，自己搭一个原子

“原子模型”仿真下面有三个篮子：质子、中子、电子。把它们拖到中间，右上角的元素周期表会实时告诉你：你搭出来的是哪种元素，是中性原子还是离子。

图 10：真实仿真截图，断网运行。我拖了 3 个质子、2 个中子、2 个电子，仿真识别为锂，并提示这是一个正离子。Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY-NC 4.0。

这张截图本身就是一道好题：为什么是“正”离子？因为质子带正电，有 3 个；电子带负电，只有 2 个；正电多一个，整体就带正电。学生自己拖一拖，比老师讲十遍记得牢。

五、现实问题：机房断网、校园网卡顿，怎么办

问题表现

很多学校的电脑机房要么不能上外网，要么几十台电脑同时打开同一个网站，加载半天。PhET 的服务器在国外，单个仿真文件约 3 到 6 MB，网络不稳定时，一节课的前十分钟可能都在转圈。

官方给的三条路

PhET 官方的离线访问页面给了三种办法。

图 11：本文原创示意图，依据 PhET 离线访问页面整理。

第一条，桌面 App：支持 Windows 和 macOS，包含全部 HTML5 和 Java 仿真及其翻译。Java 仿真需要额外安装 Java 8 开发工具包。

第二条，移动 App：Android 和 iOS 各有一个付费应用，收入用于支持新仿真开发，会自动下载新仿真。

第三条，单个下载：每个仿真页面标题下面都有下载按钮，下载下来就是一个 HTML 文件。

图 12：真实网页截图，来源 PhET Offline Access，截取于 2026-10-19。

问题分析：为什么单文件 HTML 最适合学校

桌面 App 要逐台安装，机房管理员不一定有权限；移动 App 要付费、要应用商店。而单文件 HTML 有一个很棒的特性：它把一切都打包在一个文件里。

图 13：本文原创示意图，依据本文对斜抛运动中文版文件的离线测试。

打个比方，它就像一罐压缩饼干：程序代码、图片、音效、中文界面文字，全都封在罐子里。拷到 U 盘，插到任何电脑上，双击就能用，不需要安装，也不需要服务器。

不过罐子再严实，也会附带几张“回执单”。

根因：离线打开时，仿真仍会尝试联网

我在测试时拦截了浏览器发出的所有网络请求，然后从本地打开斜抛运动的中文版文件。结果发现，仿真启动时会尝试联系三类地址：

一是 PhET 自己的使用统计，会发两次小图片请求；

二是一个第三方网站统计脚本；

三是检查这个仿真有没有新版本。

更值得注意的是，统计请求里带着当前页面的完整地址。从本地文件打开时，这个地址就是你电脑上的文件路径，可能包含电脑的用户名。

断网时这些请求都会失败，仿真照样正常运行，所以平时察觉不到。但对于注重学生隐私的学校，或者网络有严格审计的机房，这是值得知道的细节。

怎么解决：PhET 自带的开关

翻看仿真文件里的代码，会发现 PhET 已经准备了一个开关：在地址后面加上 ?yotta=false。

projectile-motion_zh_CN.html?yotta=false

我用同样的拦截方式复测：加上这个参数后，三类请求一个都没有发出，仿真功能完全正常。

需要说明的是，这些统计本身是 PhET 了解使用情况、争取经费的依据。如果你的学校能联网，也愿意支持这个免费项目，可以保留统计。下面的脚本默认关闭，但提供了一个选项打开它。

六、三端一键离线课件包：Windows 11、Ubuntu 26.04、macOS 27

我把上面的思路做成了三个脚本。它们只访问 PhET 官方网站 phet.colorado.edu，不依赖任何第三方下载站或云服务；下载完成后，整个文件夹可以离线运行。

图 14：本文原创示意图。

脚本做的事情很直白：

  1. 选清单：默认 15 个课堂常用仿真，覆盖力学、电学、光学、热学、原子、化学、数学和生物；加 --all 就下载官方列出的全部 HTML5 仿真，约 0.5 GB。
  2. 下载：优先下载你指定的语言版本，默认简体中文；某个仿真没有中文版时，自动退回英文版。
  3. 校验：检查文件里是否带有 PhET 正式版标记，避免把错误页面当成仿真保存。
  4. 建目录：生成一个 index.html 目录页，每个链接自动加上 ?yotta=false。
  5. 留指纹：生成 SHA256SUMS.txt，方便拷到其他电脑后核对文件有没有损坏。

下载入口：完整离线包 zip，或单独下载 Windows 脚本、Ubuntu 脚本、macOS 脚本。SHA-256 清单 用于核对下载文件。

方法 A：人工执行，一条命令搞定

先新建一个专门放课件的文件夹，把脚本放进去，在这个文件夹里打开终端。

Windows 11，在 PowerShell 中运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\phet-offline-windows.ps1 -Open

这里的执行策略只对这一次启动的 PowerShell 进程有效，不会修改系统设置。

Ubuntu 26.04：

bash phet-offline-ubuntu.sh --open

macOS 27：

zsh phet-offline-macos.zsh --open

常用参数如下，三端含义一致，PowerShell 用 -Lang、-Sims、-All、-Out、-Open、-AllowStats 的写法：

--lang zh_CN        语言，可换 zh_TW、en 等
--sims a,b,c        只下载指定仿真，名字取自仿真网址最后一段
--all               下载官方列出的全部 HTML5 仿真
--out 目录          输出位置，默认当前目录下的 phet-offline-<语言>
--open              完成后自动打开目录页
--allow-stats       保留 PhET 使用统计，默认关闭

比如只想给初二物理课准备三个实验：

bash phet-offline-ubuntu.sh --sims projectile-motion,forces-and-motion-basics,circuit-construction-kit-dc

运行完成后，双击 index.html，就能看到这样的目录页：

图 15：真实截图，本文 macOS 脚本生成的目录页，在拦截全部网络请求的浏览器中打开。

退出码约定：0 表示全部成功；2 表示完成了，但有个别仿真缺失，日志里会列出名字；1 表示出错。拷到机房前，把整个文件夹放进 U 盘即可，不需要在每台电脑上运行脚本。

方法 B：交给 Agent 自动配置

如果你在用 Claude Code、Codex 之类的本地 Agent，可以把 Agent 执行说明 和脚本放在同一目录，然后对它说：

请先阅读当前目录的 AGENT-INSTRUCTIONS.txt 和当前系统对应的脚本。
用 SHA256SUMS.txt 核对脚本。
在我指定的目录生成 PhET 中文离线课件包，先用默认清单。
根据退出码汇报结果，列出回退到英文或缺失的仿真。
最后在断网状态下打开 index.html，确认至少一个仿真能进入主界面。
不要修改系统设置、不要安装软件、不要上传任何文件。

说明文件限定了 Agent 的边界：只能访问 PhET 官网，不改系统配置，必须保留许可证署名；如果你打算把课件用于收费课程，它会提醒你需要商业授权。

验证范围

macOS 脚本在 macOS 27 上完整运行，15 个仿真全部下载成功，共约 58 MB；Ubuntu 脚本在 Ubuntu 24.04 服务器上实测，覆盖了中文下载、自动回退英文、缺失仿真退出码 2 等分支，本次没有 Ubuntu 26.04 实机；Windows 脚本在 PowerShell 7 容器中实测了相同分支，没有在 Windows 11 自带的 PowerShell 5.1 上实机运行，脚本按 5.1 语法编写并带 UTF-8 BOM，避免中文乱码。

七、能不能随便用：许可证要看清楚

这一点很多文章没提：PhET 仿真现在采用的是 CC BY-NC 4.0 许可证，也就是“署名-非商业性使用”。

图 16：真实网页截图，来源 PhET Licensing，截取于 2026-10-19。

翻译成大白话：

学校上课、布置作业、学生做项目、教育研究，都可以免费使用，不需要再申请许可，但要注明出处。

收费课程、订阅制产品、带广告的网站、带货或变现的视频频道、营销广告，都属于官方定义的商业用途，需要向科罗拉多大学博尔德分校申请商业授权。

署名的标准写法是：

Simulation by PhET Interactive Simulations, University of Colorado Boulder,
licensed under CC BY-NC 4.0 (https://phet.colorado.edu)

本文脚本生成的目录页底部已经自动带上这段署名。截图或录屏也属于衍生作品，分享时同样要附上。

八、Q&A：老师和家长最常问的问题

打开仿真提示“Running with low graphics quality”，怎么办？

这是浏览器没有启用 WebGL 图形加速，仿真会自动降级运行，一般不影响上课。老电脑可以更新显卡驱动，或换用新版 Chrome、Edge、Firefox。

为什么有的仿真没有中文？

中文翻译由全球志愿者完成，进度不一。截至本文核查，122 个 HTML5 仿真里有 106 个有简体中文版。缺中文的，脚本会自动下载英文版，目录页会标出 “(en)”。

iPad 能离线用吗？

可以用 Safari 打开仿真后加入阅读列表，或者购买官方 iOS App。本文的脚本面向电脑；也可以把生成的文件夹放到学校内网的一台网页服务器上，让平板通过浏览器访问。

下载的仿真会过期吗？

不会失效，但不会自动更新。PhET 偶尔会修 bug、补翻译，建议每学期重新运行一次脚本，已下载且完整的文件会自动跳过。注意：已存在的旧版文件也会被跳过，想强制更新就换一个新的输出目录。

Java 和 Flash 版的老仿真呢？

Flash 已经被所有现代浏览器淘汰，官方不再支持。Java 版需要桌面 App 加 Java 8 运行，或在线通过官方提供的转换方式运行。本文脚本只处理 HTML5 仿真，这也是官方目前主推的版本。

小学生能用吗？

能。数学类有分数、数轴、面积模型，科学类有物质状态、光的混合、平衡探究。很多仿真支持键盘操作和读屏软件，对有特殊需要的学生也比较友好。关键是用好“先猜再试”的方法，让孩子自己发现规律。

统计开关关掉，算不算对 PhET 不友好？

?yotta=false 是 PhET 自己在代码里提供的参数，不是破解。断网环境下统计本来就发不出去，关掉它只是避免无效请求和本地路径外泄。如果学校能联网，也欢迎用 --allow-stats 保留统计，或直接去官网捐赠支持这个项目。

写在最后

一间设备齐全的实验室，可能要几十万元；一个 PhET 仿真，只需要一个浏览器。它当然替代不了亲手连电路、亲眼看化学反应的体验，但它能让每一个学生，无论在城市还是乡村，都有机会先在“模拟器”里大胆试错。

把这份离线课件包拷进 U 盘，下一节课，就让学生自己去发现炮弹为什么走弧线吧。
