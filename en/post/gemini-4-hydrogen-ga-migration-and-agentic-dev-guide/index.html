1. The Master Chef & Lightning Sous-Chef (Orchestrator Economics)

Imagine running a packed restaurant. To save hourly wages, you hired an inexpensive prep cook (legacy Flash) who constantly drops plates and misreads orders. Your Michelin head chef (Carbon) ends up fixing half the dishes personally, driving total labor per order to $7.77.

2. One Giant Swimming Pool vs. a Split Bento Box (Unified 1M Context Pool)

Legacy models operated like a two-compartment bento box: one dedicated chamber for what you feed in (up to 1M input tokens), and a separate output chamber reserved solely for writing answers.

Gemini 4 Hydrogen merges everything into one single 1,048,576-token swimming pool. Your prompt (Input) + the model’s scratchpad (Thinking tokens) + your final response (Output) all swim inside that exact same pool!

Two hard physical rules follow immediately:

  • If you dump 900,000 tokens of raw logs into the pool, only 148,576 tokens remain for both scratchpad thinking and visible answers combined;
  • Watch the shared lid: max_output_tokens limits Thinking + Visible Output together. Legacy pipelines often leave conservative defaults like max_output_tokens=8192 sitting in config. Because Hydrogen thinks deeply by default, its scratchpad alone burns all 8,192 tokens, hits the lid, and yields an incomplete response with zero characters of visible text.

Also remember the faucet rule: normal synchronous requests (streaming or non-streaming) cap at 65,536 tokens (64K) per hop. To pour past 64K all the way up to the remaining pool boundary, enable the background relay pump (background=True + store=True + max_output_tokens > 65536).

3. The Four-Gear Bike & Ignored Salt Shaker (Thinking Levels & Sampling)

On older Flash models, the gearbox started at minimal, idled by default in medium, and let callers twist knobs like temperature, top_p, and top_k.

Hydrogen changes both levers dramatically:

  • Goodbye minimal, welcome high by default: Hydrogen offers strictly four gears—low, medium, high, and xhigh (called Extra in Antigravity UI). Passing thinking_level="minimal" throws an immediate error, while omitting the parameter defaults to high, billing deep reasoning traces at the $7.50 / 1M output rate;
  • The politely ignored salt shaker: If you send temperature=0.1 or top_p=0.9 in your request payload, the server returns HTTP 200 OK without complaining—and silently ignores your shaker to cook with DeepMind's calibrated defaults. Never rely on temperature=0 for valid JSON formatting again; enforce schema structure cleanly with Structured Outputs.

Deep Dive 1: Locking Down temperature / top_p / top_k & Structured Tools

Because Gemini 4 Hydrogen is RL-tuned natively for joint reasoning-and-action exploration, forcing near-zero sampling temperatures in post-training causes brittle backtracking loops during multi-step debugging. Rather than rejecting older configs, Google preserves backward request compatibility by accepting custom sampling values with HTTP 200 and neutralizing them at inference time. Enforce schemas exclusively via native Structured Outputs and declared tool schemas (avoid raw markdown-fenced JSON instructions in system prompts, which risk MALFORMED_FUNCTION_CALL).

Deep Dive 2: Breaking the 64K Output Ceiling Safely (Long Decode)

Per Google AI Studio’s Long Decode documentation, both streaming and non-streaming synchronous hops max out at 65,536 tokens. Exceeding 64K requires choosing one of two explicit paths:

  • Server-Side Interactions API: Pass BOTH background=True, store=True, and an explicit max_output_tokens > 65536 (if you pass background=True without raising max_output_tokens above 65,536, generation still stops at 64K!);
  • Client-Side SDK Continuation: Upgrade to minimum SDK versions supporting transparent client continuation—Python google-genai >= 2.34.0, JS/TS >= 2.32.0, Go >= 1.77.0, Java >= 1.80.0, .NET >= 1.28.0—and track true window occupancy via initial_input_tokens + total_output_tokens + total_thought_tokens instead of total_input_tokens.

Deep Dive 3: Capturing the 95% Implicit Caching Discount Without Busting Prefix Trees

Explicit cache objects (cachedContents / caches.create) are unsupported on Hydrogen. In exchange, Google turned Implicit Caching into a zero-config engine that automatically slashes cached input rates by 95% ($0.075 / 1M tokens) whenever consecutive requests share an exact prefix of at least 4,096 tokens. Never inject timestamps, request UUIDs, or ephemeral session IDs near the start of system instructions; pin static system prompts, shared repo maps, and tool schemas up front, appending dynamic deltas strictly at the tail.

function Invoke-RuleScan {
  param([string]$Pattern)
  $matchesList = @()
  if ($Files) {
    $matchesList = $Files | Select-String -Pattern $Pattern -AllMatches -ErrorAction SilentlyContinue
  }
  $count = 0
  $sample = ""
  if ($matchesList) {
    $count = ($matchesList | ForEach-Object { $_.Matches.Count } | Measure-Object -Sum).Sum
    $first = $matchesList | Select-Object -First 1
    if ($first) {
      $relPath = $first.Path.Substring($TargetAbs.Length).TrimStart('\','/') -replace '\\','/'
      $lineSnippet = ($first.Line.Trim() -replace '[\r\n]+', ' ')
      if ($lineSnippet.Length -gt 80) { $lineSnippet = $lineSnippet.Substring(0, 80) }
      $sample = "${relPath}:$($first.LineNumber):$lineSnippet"
    }
  }
  return [PSCustomObject]@{ Count = [int]$count; Sample = $sample }
}

$rLowCap     = Invoke-RuleScan '["'']?max_?[oO]utput_?[tT]okens["'']?\s*[:=]\s*([1-9][0-9]{0,3}|16384)([^0-9]|$)'
